# Specifications

Feature and interface specs on `develop`: `workspace`, `cli`, `core`, `contexts`, `storage`.

**Referenced but not on `develop`:** `SPEC-index`, `SPEC-graph`, `SPEC-semantic-layer`, `SPEC-lsp`, `SPEC-operations`, `SPEC-data`, `SPEC-audit`, `SPEC-execution-flow`, `SPEC-flow-memory`, `SPEC-incidents` and `SPEC-agent-prompts` exist as drafts on unmerged `docs/spec-*` branches, written before the language/framework change (they still say `angular` where they mean the framework). `SPEC-platform-setup` and `SPEC-dev-support` are not written.

Start with the [capability map](capability-map.md); one `SPEC-<module>.md` per module. [`language-framework-binaries.md`](language-framework-binaries.md) records the amendment that split `language` from `framework` and added `binaries`.
